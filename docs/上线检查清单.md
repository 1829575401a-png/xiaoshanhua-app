## 五、已知风险

1. **标准音缺失**：评分路由自动回退 demo 模式（用户自比，分数偏高）。不阻断上线，但评分准确性需录音到位后校准。
2. **微信登录为 mock**：不影响开发工具体验版测试（用测试号），正式上线前必须切换真实登录。
3. **订阅消息模板 ID 为空**：订阅流程不会触发，需在公众平台申请后填入。不阻断编译/体验版，仅影响推送功能。
4. **朋友圈分享需海报图**：`SHARE_POSTER` 为空时仅"发送给朋友"可用。

## 六、发布步骤

1. **微信开发者工具**：打开 `/workspace/xiaoshanhua-app/miniprogram`
2. 确认控制台无红色报错，页面渲染正常
3. 点击**上传**按钮 → 填写版本号 `v1.1.0` → 提交
4. 在 mp.weixin.qq.com → 版本管理 → 设为**体验版**
5. 扫码体验 → 确认无阻断问题 → 提交审核
6. 审核通过（1-7 个工作日）→ 发布上线
